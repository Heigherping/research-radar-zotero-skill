## 1. 先讲清楚这篇论文

用连贯中文解释它要解决什么具体失败、核心主张是什么、证据最远支持到哪里。

## 2. 问题从哪里来，作者押注了什么

研究背景 → 原方法的具体限制 → 关键假设 → 作者的方案。区分作者明确写出的动机与我的分析。

## 3. 方法如何工作

说明输入、输出、处理步骤及各模块作用，解释不可缺少的设计与可替代部分。算法论文讲数据流与训练/推理；仪器论文讲光路、采集、标定与测量链。

## 4. 关键公式、符号与算例

先解释公式用途，再给符号、维度、单位与假设；对关键公式给可算完的数值例子。算例标为教学构造，不冒充原文数据。没有关键公式时写明不适用。

## 5. 实验设计与公平对照

样品/数据来源、独立实验单位、训练/验证/测试划分、基线选参、消融与外部验证。逐项说明已报告和未报告的信息。

## 6. 图表与关键证据

| 图表 / 页码 | 实际比较什么 | 支持的主张 | 不能推出什么 / 反例 |
|---|---|---|---|
|  |  |  |  |

覆盖实际阅读范围内的主要图表，解释曲线、误差条、坐标与失败案例，不只改写图注。

## 7. 结果、贡献与证据边界

将数值与条件、单位、分母和来源位置一起记录；区分原文结果、作者推断和我的分析。

## 8. 局限与尚未回答的问题

适用条件、缺少的对照、数据泄漏风险、可辨识性/泛化限制及复现缺口；缺证据时不补猜。

## 9. 与我的研究有什么关系

对应最新研究画像中的具体问题，说明可借鉴环节与迁移条件。光谱任务区分谱贡献与含量、重构与身份核验；部署任务分别检查运算、内存、精度和资源证据。

## 10. 最小复现或验证计划

目标、输入与真值、基线/对照、分组方式、指标、所需资源和停止条件。明确这些是本项目建议，并非论文已完成的实验。
